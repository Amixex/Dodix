# Dodix Додо Радар 🍕

Приложение для мониторинга новостей города Фрязино с интеграцией локальной нейросети (Qwen) для генерации маркетинговых идей.

## Как скачать APK
1. Перейдите во вкладку **Releases** в правой части этого репозитория.
2. Скачайте последний файл `app-debug.apk`.
3. На телефоне разрешите установку из неизвестных источников (Настройки -> Безопасность -> Установка неизвестных приложений).
4. Установите APK.

## Как загрузить модель
При первом запуске приложение попросит скачать модель (например, Qwen2.5-4B-Instruct-GGUF).
* Убедитесь, что у вас есть Wi-Fi и хотя бы 4 ГБ свободного места.
* Модель скачивается во внутреннее хранилище приложения.
* Вы можете удалить модель в любой момент в настройках, чтобы освободить место.

## Тестовый режим
В настройках есть кнопка «Тест». Она прогоняет 3 встроенные новости через модель без интернета, чтобы проверить работоспособность.
