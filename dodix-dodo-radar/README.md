# 🍕 Dodix Додо Радар

Android-приложение для локального маркетолога Додо Пиццы во Фрязино. Каждый день собирает городские новости, отбирает полезные для пиццерии и предлагает идеи активностей. **Всё работает на телефоне**: без сервера, без внешних ИИ-API и ключей. Анализ делает модель Qwen3.5 (GGUF), запущенная через llama.cpp прямо на устройстве.

> ⚠️ **Статус:** код написан, но **ни разу не собирался и не запускался** (в среде разработки нет Android SDK и интернета). Первая сборка в GitHub Actions вполне может упасть на мелкой ошибке: пришлите лог, поправим. Скорость модели на телефоне и качество идей нужно проверить вживую.

## 1. Как получить APK
1. Создайте на github.com пустой репозиторий (например, `dodix-dodo-radar`).
2. Загрузите в него **всё содержимое** этого архива (кнопка *Add file → Upload files*; папка `.github` должна попасть в репозиторий. Если веб-загрузка её пропускает, используйте `git push`).
3. Откройте вкладку **Actions** → workflow **Build APK** → дождитесь зелёной галочки. Первая сборка долгая: **15–25 минут**, потому что компилируется llama.cpp.
4. Внутри запуска, раздел **Artifacts**, скачайте `Dodix-Dodo-Radar-debug-apk` (zip с APK).
5. Для постоянной ссылки создайте тег: `git tag v1.0.0 && git push origin v1.0.0`, и APK появится в **Releases**.

Подпись не нужна: APK подписывается debug-ключом.

## 2. Установка на Samsung
1. Скопируйте APK на телефон и откройте его в «Мои файлы» (или из браузера).
2. Android попросит разрешить установку из этого источника: **Настройки → разрешить из этого источника** → вернитесь и нажмите «Установить».
3. Если Play Protect предупредит, выберите «Всё равно установить» (приложение не из магазина).
4. Разрешите уведомления при первом запуске.
5. **Важно для автосводки:** Настройки телефона → Приложения → Додо Радар → Батарея → **«Не ограничивать»**. Иначе One UI может не запустить сводку в 09:00.

## 3. Загрузка модели
Вкладка **«Модель»**: выберите размер (4B по умолчанию, для 8 ГБ ОЗУ и больше; 2B для слабых телефонов) → **«Скачать»**. Нужно ≈3 ГБ свободного места (по умолчанию только Wi-Fi). Загрузка продолжается при обрыве (кнопка «Докачать») и проверяется по SHA-256. Если Hugging Face недоступен, вставьте свою ссылку на `.gguf` в поле «своя ссылка».

Модели: [unsloth/Qwen3.5-4B-GGUF](https://huggingface.co/unsloth/Qwen3.5-4B-GGUF) (Q4_K_M, Apache-2.0). Адрес файла 2B (`unsloth/Qwen3.5-2B-GGUF`) составлен по тому же шаблону и **не проверен**: если приложение скажет «ссылка недоступна», используйте поле своей ссылки.

## 4. Как это работает
1. Сбор за 48 часов из источников (RSS / публичные Telegram-каналы `t.me/s/<канал>` / HTML-страницы по CSS-селектору). Дубли отсекаются по URL. Недоступный источник пропускается с записью в журнал.
2. Фильтр: обязательное слово города (по умолчанию «фрязин») и ключевые слова (редактируются в настройках).
3. Модель выбирает до 3 новостей и даёт по одной идее с причиной. Ответ строго JSON (грамматика GBNF), размышления Qwen3.5 отключены, температура 0,3, до 2 повторов. Если ничего не подходит, список пустой.
4. Автосводка раз в день (время в настройках; по умолчанию 09:00) при сети и зарядке или заряде от 30 %. Кнопка «Обновить сейчас» на главном экране.

Источники по умолчанию (то, что вы прислали): Telegram-канал «Щелково • Ивантеевка • Фрязино» (включён; берутся только публикации с упоминанием Фрязина) и страница fryazino.info из вашей ссылки (**выключена**: это раздел «Бизнес», а не новости; на вкладке «Источники» замените её адресом новостного раздела или RSS).

## 5. Ограничения
- Скорость: на Exynos 2100 ожидайте несколько токенов в секунду, сводка занимает минуты. Телефон греется.
- Модель 4B может ошибаться и общаться шаблонно. Идеи нужно проверять по ссылке.
- Сводка в фоне ограничена системой (~10 минут на задачу); при сбое повторяется.
- Сайты, строящие страницу на JavaScript, парсером HTML не читаются: нужен RSS.

## 6. Для разработчиков
Kotlin, Jetpack Compose, Room, WorkManager, OkHttp, Jsoup. llama.cpp подтягивается CMake FetchContent на закреплённом теге (`app/src/main/cpp/CMakeLists.txt`, `GIT_TAG b9222`); JNI-обёртка: `llm_jni.cpp`. Сборка: `gradle :app:assembleDebug` (Gradle 8.10, JDK 17, NDK 27.2, CMake 3.22.1). Секретов в репозитории нет; `.gguf` исключены из git.
